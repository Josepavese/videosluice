# Naming decision — 2026-10-11

VideoSluice: a sluice controls and distributes a flow. The name combines the
media handled with the broker's role: one capture owner, controlled outputs to
live delivery, archive and frame analysis. Command/repository: `videosluice`.

GitHub repository search API, queries `VideoSluice in:name`, `FrameSluice in:name`
and `CamSluice in:name`: zero results at selection time. Exact web searches for
all three names also returned no results. This is a dated search result, not a
trademark clearance or guarantee against future collisions.

Rejected: CamRelay (existing video projects), FrameHarbor (existing media app),
FramePort (multiple existing projects, including video capture). VideoSluice was
preferred over the remaining candidates because it explicitly names video.

Sources: https://api.github.com/search/repositories?q=VideoSluice+in:name ;
https://github.com/FAMJAM1/CamRelay ; https://github.com/esghound3-maker/frameharbor ;
